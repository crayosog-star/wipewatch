Steam's official server list needs a key. It is free and takes a minute. The key stays on this PC and is only sent to Steam.

  2. For Domain Name type anything (e.g. localhost), tick the agreement and click Register.
  3. Copy the Key shown on that page and paste it below.

Twitch

Twitch needs a one-time setup (free, about 2 minutes). Without it the app can't see which Rust streams have drops live.

  1. Click Open Twitch developer console and log in.
  2. Register an application: Name anything (e.g. Wipewatch), OAuth Redirect URL http://localhost, Category Application Integration, Client Type Public.
  3. Click Manage on the new app and copy the Client ID (it is not a secret).
  4. Paste it below, click Save changes, then Link Twitch and enter the code on the Twitch page that opens.
