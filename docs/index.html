Wipewatch watches drops, prices, servers and updates for you, then plans your wipe and keeps your crew in the loop.

Built for how you actually play

Nine tools that used to be nine browser tabs, quietly running in your tray.

Alerts

Drops

See at a glance whether any Rust drop is live on Kick or Twitch and what it gives. Get notified the moment one starts or is about to end.

Market

Skins

Your public Steam inventory priced from the market: total value, value after fees, history, price alerts, a watchlist and profit and loss on what you paid.

Live

Servers

Players, queue and the map for the current wipe. Favourite a server and get told when its queue shortens or it wipes, then join in one click.

Social

Friends & Clans

Add friends, share only what you choose, and form a clan with a combined skin value. Open or private, with a switch for every field.

Inspiration

Build Ideas

Fresh, popular base-build videos from the creators you follow, ranked by views for their age and filterable by group size and style.

Planning

Wipe Planner

A wipe-day checklist that resets itself every force wipe, notes, and pins for your base on each server's map.

News

Patch Notes

Official update posts with images, and a live countdown to the next monthly update and force wipe.

Tools

Raid Calculator

Work out the sulfur and explosives for a raid. The cost table is fully editable.

Polish

Made to live with

Command palette, light and dark themes, an always-on-top mini overlay, alert sounds, quiet hours, backups and a launch animation.

Your crew, on your terms

Friends and clans run on a small server your group hosts. You decide what anyone sees, and the server enforces it.

  • Open or private. Open profiles can be found by name; private ones need your exact username and are visible to friends only.
  • A switch for every field. Skin value, activity, recent servers, hours played, playing now. Off means never sent.
  • No emails, no passwords. Your PC holds a private key; the server only stores a hash. Delete your account any time.
  • Zero-dependency server. One file, about 70 automated checks.
node server/server.js

# Wipewatch  ->  Friends
#   server address + a username
#   -> your profile is live

Get it

Windows 10 and 11. Download the Solo installer from Releases, or build it from source with only the tools already on Windows.

  • Per-user install. No admin rights, Start Menu and Desktop shortcuts, proper uninstaller.
  • Solo edition. The same app without Friends and Clans, for people who only want the tools.
  • Unsigned. Windows SmartScreen may ask you to confirm the first run.
git clone https://github.com/crayosog-star/wipewatch
cd wipewatch
npm install
npm run installer        # full edition
npm run installer:solo   # solo edition
